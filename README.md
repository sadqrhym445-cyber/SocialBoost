# SocialBoost — النسخة التجريبية

موقع عربي متجاوب ومناسب للآيفون، يضم صفحة خدمات، أداة إنشاء مسودات محتوى، ونموذج طلبات.

## الموجود حالياً
- واجهة عربية RTL متجاوبة مع الهاتف.
- أداة محلية لتوليد مسودة كابشن وهاشتاغات (قوالب داخل المتصفح وليست نموذج ذكاء اصطناعي).
- حفظ الطلبات في `localStorage` على نفس الجهاز فقط.
- لا توجد إعجابات أو متابعات آلية، ولا يوجد ربط فعلي بحسابات التواصل في هذه النسخة.
- مخطط SQL اختياري لبدء إضافة Supabase في المرحلة التالية.

## التشغيل من الآيفون
1. فك ضغط ملف المشروع في تطبيق الملفات.
2. ارفع مجلد المشروع إلى مستودع GitHub (يمكن إنشاء المستودع من Safari أو تطبيق GitHub).
3. من Vercel استورد مستودع GitHub وانشر الموقع. يمكن أيضاً استخدام أي استضافة static تدعم HTML/CSS/JS.
4. افتح رابط الموقع في Safari، ثم اضغط مشاركة > إضافة إلى الشاشة الرئيسية.

يمكن تجربة الواجهة محلياً بفتح `index.html`، لكن بعض خصائص النسخ والحفظ قد تختلف بحسب المتصفح. النشر على HTTPS أفضل.

## النشر المجاني
- أنشئ حساباً في GitHub وVercel.
- ارفع الملفات مع الحفاظ على هيكلها.
- في Vercel اختر New Project ثم Import Git Repository ثم Deploy.
- لأن المشروع حالياً static ولا يحتوي build command، اترك إعدادات البناء فارغة أو استخدم إعداد static المناسب.
- لا ترفع أي مفاتيح سرية إلى المستودع.

## تشغيل الطلبات بشكل حقيقي
النموذج الحالي يحفظ الطلبات على جهاز المستخدم نفسه، ولا يرسلها لصاحب الموقع. لتلقي طلبات العملاء من أجهزة مختلفة:
1. أنشئ مشروع Supabase.
2. نفّذ `supabase-schema.sql` في SQL Editor.
3. أضف تسجيل الدخول، ثم اربط نموذج الطلب بقاعدة البيانات عبر عميل آمن وسياسات RLS مناسبة.
4. أضف لوحة إدارة منفصلة للمشرف، ولا تمنح المستخدمين صلاحية الاطلاع على طلبات الآخرين.
5. اختبر الأمان قبل نشر النسخة العامة.

## الربط الرسمي مع المنصات
### Meta: Facebook Pages وInstagram
- أنشئ تطبيقاً في Meta for Developers.
- استخدم OAuth وصلاحيات صفحات فيسبوك المناسبة.
- واجهة Instagram الرسمية موجهة للحسابات الاحترافية (Creator/Business) حسب المنتج والصلاحيات.
- قد تحتاج إلى App Review وصلاحيات معتمدة قبل خدمة مستخدمين آخرين.
- لا يمكن نشر المحتوى إلى حسابات شخصية عادية كما لو كان حساب صفحة.

وثائق: https://developers.facebook.com/docs/ و https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api/

### TikTok
- أنشئ تطبيقاً في TikTok for Developers وأضف المنتجات المطلوبة.
- عرض الملف والفيديوهات يختلف عن صلاحية نشر المحتوى.
- النشر المباشر يحتاج Content Posting API، موافقة على النطاقات المطلوبة، وموافقة المستخدم. قد يظل نشر تطبيق غير مدقق خاصاً فقط.
- لا يمكن استخدام واجهات API الرسمية لزيادة الإعجابات أو المتابعين بشكل آلي.

وثائق: https://developers.tiktok.com/doc/ و https://developers.tiktok.com/docs/en/content-posting-api-get-started/

## الخطوات التالية المقترحة
1. إضافة تسجيل دخول بالبريد الإلكتروني.
2. تخزين الطلبات في Supabase مع RLS ولوحة إدارة.
3. ربط OAuth الرسمي لـ Meta وTikTok بعد إنشاء التطبيقات والحصول على الموافقات.
4. إضافة تحليلات فعلية فقط للمقاييس التي تسمح بها الصلاحيات.
5. اختبار الخصوصية والأمان على الهاتف.

## تنبيه
هذا مشروع بداية قابل للتشغيل، وليس خدمة تسويق منشورة ومربوطة بحساباتك بالفعل. لا تدخل كلمات مرور حسابات التواصل أو رموز التحقق في نموذج الطلب.
